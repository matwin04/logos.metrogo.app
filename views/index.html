Three ways to pull a mark

Pick whichever fits the surface — a raw image tag, a fetch from a script, or a class from the generated stylesheet.

HTML <img>
<img src="https://logos.metrogo.app/api/metro~losangeles/main.svg" alt="LA Metro" />
curl
curl -o metro.svg https://logos.metrogo.app/api/metro~losangeles/main.svg
CSS class (via logo.css)
/* style.css */
.agency-badge {
  width: 48px;
  height: 48px;
}
index.html
<span class="agency-badge logo logo-metro-losangeles"></span>
